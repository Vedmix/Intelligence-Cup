# Смена пароля базы NSS повреждает исходные данные ключей ML-DSA

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-127671 |
| Компонент | NSS |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Смена пароля базы NSS повреждает исходные данные ключей ML-DSA.

## Решение

Используйте сборку компонента «NSS» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-127671.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После смены пароля хранилища NSS ключи ML-DSA становятся непригодны.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версия NSS, формат базы и результат операции с тестовым ключом до и после смены. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Загрузка с NFS срывается в режиме enforcing

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2218207 |
| Компонент | SELinux |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Загрузка с NFS срывается в режиме enforcing.

## Решение

Используйте сборку компонента «SELinux» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2218207.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- При permissive корень на NFS загружается, а при enforcing загрузка срывается.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Параметры загрузки, тип NFS-корня, режим SELinux, консоль и AVC. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

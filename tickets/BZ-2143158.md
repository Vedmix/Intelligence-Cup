# nodedev-dumpxml неверно выводит атрибуты некоторых mediated devices

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2143158 |
| Компонент | libvirt |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

nodedev-dumpxml неверно выводит атрибуты некоторых mediated devices.

## Решение

Используйте сборку компонента «libvirt» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2143158.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- В XML mediated device отсутствуют либо неверно указаны ожидаемые атрибуты.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Тип mdev, версия libvirt и вывод virsh nodedev-dumpxml. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

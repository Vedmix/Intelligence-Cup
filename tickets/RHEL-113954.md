# Повторное применение профиля не поддерживает изменение sriov.vfs

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-113954 |
| Компонент | NetworkManager |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Повторное применение профиля не поддерживает изменение sriov.vfs.

## Решение

Используйте сборку компонента «NetworkManager» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-113954.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Изменения числа SR-IOV VF нельзя применить к активному профилю через reapply.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Профиль с sriov.vfs, версия NetworkManager, модель NIC и результат reapply. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

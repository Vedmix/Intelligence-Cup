# Установщик не может установить загрузчик на диск с разделом PReP

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2026579 |
| Компонент | Установщик RHEL / загрузчик |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.2 |

## Симптомы

Установка на PowerPC завершается ошибкой загрузчика на диске с секторами 4 КиБ, если раздел PReP имеет размер, отличный от 4 или 8 МиБ.

## Причина

Установщик не поддерживал эту комбинацию размера сектора и раздела PReP.

## Решение

Повторите установку с носителя RHEL, содержащего исправление установщика.

## Проверка

В тестовой установке с исходной разметкой проверьте успешную установку загрузчика и запуск с целевого диска.

## Диагностика на стенде

Запишите версию установочного образа, размер сектора и размер PReP. В среде установщика размер логического сектора можно посмотреть через `lsblk -o NAME,LOG-SEC,PHY-SEC,SIZE`. Для сравнения используйте ту же разметку на тестовом диске и сохраните журнал установки при ошибке загрузчика.

## Переписка в Bugzilla

Комментарии Bugzilla не удалось прочитать. Описание причины и решения взято из примечаний Red Hat к выпуску.

## Другие формулировки симптома

- На PowerPC установка доходит до загрузчика и срывается при нестандартном размере PReP.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Размер PReP, размер логического сектора, разметка и журнал Anaconda. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

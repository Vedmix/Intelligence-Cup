# Режим LDAP referral не работает корректно

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2053204 |
| Компонент | Directory Server |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Режим LDAP referral не работает корректно.

## Решение

Используйте сборку компонента «Directory Server» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2053204.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- LDAP-сервер в режиме перенаправления выдаёт неверный ответ.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Настройки referral, запрос и ответ LDAP, журнал доступа. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

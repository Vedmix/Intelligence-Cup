# Обновление списка SCSI-устройств вызывает перезапуск ресурсов кластера

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2177996 |
| Компонент | pcs |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Обновление списка SCSI-устройств вызывает перезапуск ресурсов кластера.

## Причина и условия

После изменений в CIB Pacemaker команда `pcs stonith update-scsi-devices` могла вызвать перезапуск ресурсов.

## Решение

После обновления `pcs` проверьте изменение списка устройств в тестовом кластере и сопоставьте состояние ресурсов до и после операции.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- При изменении списка SCSI-дисков STONITH кластер неожиданно рестартует ресурсы.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Команда update-scsi-devices, состояние ресурсов и журнал Pacemaker. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# eu-addr2line -i неверно обрабатывает код после GCC LTO

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2236182 |
| Компонент | elfutils |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

eu-addr2line -i неверно обрабатывает код после GCC LTO.

## Решение

Используйте сборку компонента «elfutils» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2236182.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Для LTO-бинарника eu-addr2line не показывает ожидаемую цепочку встроенных функций.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версии GCC и elfutils, флаги LTO и DWARF, бинарник или минимальный пример. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

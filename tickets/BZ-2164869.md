# Ключ persistent reservation присутствует не на всех путях

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2164869 |
| Компонент | DM Multipath |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Ключ persistent reservation присутствует не на всех путях.

## Причина и условия

Новые пути, появившиеся при остановленной `multipathd`, могли остаться без ключа резервирования.

## Решение

Обновите DM Multipath. В изолированном стенде проверьте регистрацию ключа на всех активных путях после повторного запуска службы.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Резервирование SCSI действует не на всех путях одного multipath-устройства.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Список путей, время рестарта multipathd и статус регистрации ключа. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

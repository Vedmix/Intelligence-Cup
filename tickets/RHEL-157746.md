# Политика перезапуска контейнера не применяется при загрузке системы

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-157746 |
| Компонент | Podman |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Политика перезапуска контейнера не применяется при загрузке системы.

## Причина и условия

После перезагрузки `podman-restart.service` мог не запускать контейнеры с политикой `unless-stopped`.

## Решение и проверка

На тестовом узле с обновлённым Podman запустите контейнер с `--restart=unless-stopped`, затем перезагрузите узел. Проверьте состояние контейнера через `podman ps` и журнал службы.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После перезагрузки Podman не поднимает контейнер с unless-stopped.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Политика из podman inspect, версия Podman и журнал podman-restart.service. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

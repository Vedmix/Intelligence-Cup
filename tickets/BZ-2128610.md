# Система не обнаруживает NVMe после сброса при включённом VMD

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2128610 |
| Компонент | VMD / NVMe |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Система не обнаруживает NVMe после сброса при включённом VMD.

## Причина и условия

При переподключении драйвера не выполнялся мягкий сброс домена VMD, из-за чего устройства не перечислялись повторно.

## Решение

Загрузите исправленное ядро. На тестовом узле с VMD сравните `lsblk` до и после сценария сброса. Ожидаемые NVMe должны появиться снова.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После сброса драйвера NVMe за Intel VMD перестаёт определяться.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** lspci, lsblk и журнал ядра до и после сброса. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

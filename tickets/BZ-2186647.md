# Провайдер XML-подписей OpenJDK не работает в FIPS

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2186647 |
| Компонент | OpenJDK |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Провайдер XML-подписей OpenJDK не работает в FIPS.

## Решение

Используйте сборку компонента «OpenJDK» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2186647.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Java не может создать или проверить XML-подпись в окружении FIPS.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Сборка JDK, провайдер XMLDSig, режим FIPS и исключение. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

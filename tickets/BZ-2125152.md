# HNV bond теряет настройку основного порта после перезагрузки

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2125152 |
| Компонент | NetworkManager / hcnmgr |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.2 |

## Симптомы

На системе с Hybrid Network Virtualization после перезагрузки теряется настройка основного порта bond.

## Причина

Создание HNV bond через API NetworkManager не сохраняло требуемую настройку порта.

## Решение

Обновите компоненты до сборок с исправлением. `nmcli` использует `hcnmgr` для задания параметров основного порта.

## Проверка

Сравните параметры HNV bond до и после перезагрузки тестовой системы. Проверьте основной порт и `primary_reselect`.

## Диагностика на стенде

Сохраните вывод `nmcli device status` и `/proc/net/bonding/<имя-bond>` до и после перезагрузки. Сравните `Primary Slave` и политику `primary_reselect`. Активный порт может меняться в зависимости от доступности линка, поэтому отдельно проверяйте сохранение настройки основного порта.

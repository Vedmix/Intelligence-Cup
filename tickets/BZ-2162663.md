# SELinux блокирует регистрацию в Insights через cloud-init

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2162663 |
| Компонент | cloud-init |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

SELinux блокирует регистрацию в Insights через cloud-init.

## Решение

Используйте сборку компонента «cloud-init» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2162663.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Облачный экземпляр не регистрируется в Red Hat Insights на этапе cloud-init.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Журнал cloud-init, результат регистрации и AVC в тот же момент. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

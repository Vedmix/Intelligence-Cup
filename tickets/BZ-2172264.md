# oscap-anaconda-addon не применяет профиль CIS Network Servers

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2172264 |
| Компонент | OpenSCAP |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

oscap-anaconda-addon не применяет профиль CIS Network Servers.

## Решение

Используйте сборку компонента «OpenSCAP» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2172264.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Установщик не может применить профиль укрепления CIS для сетевого сервера.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** ID профиля, версия oscap-anaconda-addon и журнал установки. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

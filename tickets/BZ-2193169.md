# Автоматическое исправление настроек journald добавляет лишние кавычки

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2193169 |
| Компонент | OpenSCAP |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Автоматическое исправление настроек journald добавляет лишние кавычки.

## Условия и признаки

После применения исправлений SCAP настройки `Compress`, `ForwardToSyslog` или `Storage` могут присутствовать в `/etc/systemd/journald.conf`, но служба их игнорирует. Сканирование при этом может показать `pass`.

## Причина

Сценарии исправления для `journald_compress`, `journald_forward_to_syslog` и `journald_storage` добавляли лишние кавычки.

## Диагностика и проверка исправления

Сравните файл до и после применения исправления в тестовой системе. Обновите `scap-security-guide`, повторите исправление на копии исходной конфигурации и проверьте журнал `journalctl -b -u systemd-journald` и фактическое применение нужной настройки.

## Решение
Используйте сборку компонента «OpenSCAP» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2193169.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После ремедиации SCAP journald игнорирует значения, обёрнутые в лишние кавычки.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Изменённые строки journald.conf, ID правила, вывод скана и журнал службы. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

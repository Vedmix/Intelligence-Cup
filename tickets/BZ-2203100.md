# dnf needs-restarting -s выводит неверный список служб

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2203100 |
| Компонент | DNF |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

dnf needs-restarting -s выводит неверный список служб.

## Причина и условия

При обходе процессов команда прерывалась на процессе, которым не управлял systemd, или на процессе с ошибкой.

## Решение и проверка

После обновления запустите `dnf needs-restarting -s`. При обнаружении такого процесса команда должна выдать предупреждение и продолжить вывод списка служб.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Проверка нуждающихся в рестарте служб DNF спотыкается об отдельный процесс.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версия плагина, stderr и сведения о проблемном процессе и его systemd unit. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Модуль ipa-kdb вызывает сбой krb5kdc

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2227831 |
| Компонент | IdM / Kerberos |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Модуль ipa-kdb вызывает сбой krb5kdc.

## Условия и признаки

В IdM служба `krb5kdc` иногда завершается при проблемах подключения к LDAP.

## Причина

`ipa-kdb` обрабатывал отсутствие объекта хоста и отказ соединения одинаково. После отказа соединения он мог использовать пустой контекст LDAP.

## Диагностика и проверка исправления

Сопоставьте время остановки KDC с журналом Directory Server и событиями связи с LDAP. После установки обновления на стенде повторите отказ LDAP. Критерий исправления — процесс KDC остаётся запущенным, даже если отдельный запрос завершается ошибкой из-за недоступности LDAP.

## Решение
Используйте сборку компонента «IdM / Kerberos» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2227831.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- KDC останавливается после потери соединения с LDAP.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Журналы krb5kdc и Directory Server за один интервал, состояние связи с LDAP. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Можно удалить встроенную учётную запись admin

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2229712 |
| Компонент | IdM |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Можно удалить встроенную учётную запись admin.

## Решение

Используйте сборку компонента «IdM» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2229712.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Встроенный администратор IdM удаляется обычной операцией удаления пользователя.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версия IPA, подкоманда и результат на тестовом домене. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

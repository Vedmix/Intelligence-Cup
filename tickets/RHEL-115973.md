# Для глобального домена поиска DNS приходится указывать DNS-сервер

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-115973 |
| Компонент | NetworkManager |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Для глобального домена поиска DNS приходится указывать DNS-сервер.

## Решение

Используйте сборку компонента «NetworkManager» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-115973.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Задание только глобального DNS search отклоняется без адреса резолвера.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Глобальная DNS-конфигурация, способ её задания и вывод клиента NetworkManager. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

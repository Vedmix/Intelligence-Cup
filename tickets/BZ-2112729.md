# Роль SELinux staff_r не может запускать проверки SCAP Workbench

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2112729 |
| Компонент | SCAP Workbench |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Роль SELinux staff_r не может запускать проверки SCAP Workbench.

## Решение

Используйте сборку компонента «SCAP Workbench» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2112729.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- SCAP Workbench работает в одном контексте, но проверка не запускается из staff_r.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** id -Z, имя профиля SCAP и журнал с AVC. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

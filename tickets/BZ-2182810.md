# Веб-интерфейс pcsd не показывает состояние кластера с уровнями fencing

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2182810 |
| Компонент | pcsd |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Веб-интерфейс pcsd не показывает состояние кластера с уровнями fencing.

## Причина и условия

Сбой возникает в кластере с настроенными уровнями fencing. В браузере не загружается страница состояния кластера.

## Решение

Установите обновление `pcs`. На тестовом кластере с уровнями fencing откройте страницу состояния и убедитесь, что она загружается и позволяет просматривать настройки.

## Переписка

29 марта 2023 Михал Поспишил зарегистрировал сбой и приложил журнал консоли браузера. В Bugzilla указана сборка `pcs-0.11.5-1.el9`. Тикет закрыт после [RHSA-2023:6316](https://access.redhat.com/errata/RHSA-2023:6316).

## Другие формулировки симптома

- Страница состояния pcsd не открывается после добавления уровней изоляции узлов.

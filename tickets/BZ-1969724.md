# Failover-интерфейс virtio в Windows не получает IP-адрес

| Поле | Значение |
| --- | --- |
| Тикет | BZ#1969724 |
| Компонент | Виртуализация / virtio |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Failover-интерфейс virtio в Windows не получает IP-адрес.

## Решение

Используйте сборку компонента «Виртуализация / virtio» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#1969724.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Windows-гость не получает адрес на резервной паре сетевых устройств virtio.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** XML интерфейсов ВМ, драйвер virtio, ipconfig и данные DHCP. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

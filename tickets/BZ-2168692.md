# Роль storage не меняет размер смонтированной файловой системы без размонтирования

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2168692 |
| Компонент | Системная роль storage |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Роль storage не меняет размер смонтированной файловой системы без размонтирования.

## Решение

Используйте сборку системных ролей с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2168692.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Изменение размера файловой системы через Ansible требует её размонтировать.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Переменные роли, тип ФС, findmnt и вывод задачи изменения размера. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

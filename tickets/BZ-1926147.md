# Установщик в ВМ не показывает ожидаемый системный диск

| Поле | Значение |
| --- | --- |
| Тикет | BZ#1926147 |
| Компонент | Anaconda / виртуализация |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Установщик в ВМ не показывает ожидаемый системный диск.

## Решение

Используйте сборку компонента «Anaconda / виртуализация» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#1926147.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- При установке RHEL в виртуальной машине нужный загрузочный диск не предлагается.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** XML дисков ВМ, порядок загрузки и журнал Anaconda. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

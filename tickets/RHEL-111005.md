# Пакет glibc-locale-source не подтягивает gzip для сжатых таблиц символов

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-111005 |
| Компонент | glibc |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Пакет glibc-locale-source не подтягивает gzip для сжатых таблиц символов.

## Решение

Используйте сборку компонента «glibc» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-111005.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- В минимальной системе не удаётся прочитать сжатые таблицы локалей без gzip.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версия glibc-locale-source, наличие gzip и ошибка команды локализации. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

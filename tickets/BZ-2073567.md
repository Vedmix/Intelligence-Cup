# gpg-agent не работает как SSH-агент в режиме FIPS

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2073567 |
| Компонент | GnuPG |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

gpg-agent не работает как SSH-агент в режиме FIPS.

## Решение

Используйте сборку компонента «GnuPG» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2073567.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- В режиме FIPS SSH-клиент не может использовать gpg-agent для аутентификации.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Тип ключа, SSH_AUTH_SOCK, состояние FIPS и отладочный вывод SSH без ключей. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# liveimg проверяет HTTPS-сертификат вопреки --noverifyssl

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2157921 |
| Компонент | Anaconda |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

liveimg проверяет HTTPS-сертификат вопреки --noverifyssl.

## Решение

Используйте сборку компонента «Anaconda» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2157921.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Загрузка liveimg прерывается проверкой сертификата, хотя в Kickstart разрешено её пропустить.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Строка liveimg из Kickstart, ошибка TLS и журнал Anaconda. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

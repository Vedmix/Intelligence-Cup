# Установщик не проверяет соответствие парольной фразы LUKS требованиям FIPS

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2163497 |
| Компонент | Anaconda |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Установщик не проверяет соответствие парольной фразы LUKS требованиям FIPS.

## Решение

Используйте сборку компонента «Anaconda» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2163497.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- На установке в FIPS можно пройти шаг настройки LUKS с фразой, не удовлетворяющей требованиям.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Режим FIPS, сценарий ввода и сообщения установщика без самой парольной фразы. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

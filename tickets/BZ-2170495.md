# Политика SELinux блокирует репликацию почты

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2170495 |
| Компонент | Dovecot |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Политика SELinux блокирует репликацию почты.

## Условия и признаки

Dovecot настроен на двустороннюю репликацию. Доставка работает, но репликация сообщений между узлами не проходит при применении политики SELinux.

## Причина

Политика не разрешала `dovecot-deliver` обмен данными через канал в файловой системе времени выполнения.

## Диагностика и проверка исправления

Сопоставьте время доставки тестового сообщения с отказами SELinux в `ausearch -m AVC -ts recent`. После обновления политики повторите доставку и проверьте появление сообщения на втором узле.

## Решение
Используйте сборку компонента «Dovecot» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2170495.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Двусторонняя синхронизация почты Dovecot останавливается из-за запрета доступа к каналу.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Конфигурация репликации, журнал Dovecot и AVC для dovecot-deliver. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# dnf-automatic не рассылает уведомление нескольким адресатам через mail

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-94321 |
| Компонент | DNF Automatic |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

dnf-automatic не рассылает уведомление нескольким адресатам через mail.

## Решение

Используйте сборку компонента «DNF Automatic» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-94321.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Автоматические уведомления DNF не доходят до нескольких получателей, заданных для mail.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Настройки emitter без адресов, список получателей по количеству и журналы mail. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Резервный watchdog fencing не учитывается в общем тайм-ауте

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2182482 |
| Компонент | Pacemaker |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Резервный watchdog fencing не учитывается в общем тайм-ауте.

## Решение

Используйте сборку компонента «Pacemaker» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2182482.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После тайм-аута первого fencing-устройства операция истекает раньше резервного watchdog.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Топология fencing, тайм-ауты и события Pacemaker по времени. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

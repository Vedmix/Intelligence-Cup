# Онлайн-инициализация потребителя LDAP завершается LDAP_BUSY

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-129559 |
| Компонент | Directory Server |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Онлайн-инициализация потребителя LDAP завершается LDAP_BUSY.

## Решение

Используйте сборку компонента «Directory Server» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-129559.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Инициализация LDAP-реплики по сети прерывается ответом «сервер занят».

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Размер базы, состояние потребителя, журналы и код LDAP_BUSY. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Схема каталога не реплицируется корректно

| Поле | Значение |
| --- | --- |
| Тикет | BZ#1759941 |
| Компонент | Directory Server |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Схема каталога не реплицируется корректно.

## Решение

Используйте сборку компонента «Directory Server» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#1759941.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После изменения схемы реплика Directory Server остаётся со старой схемой.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Определение изменённого атрибута, топология и журналы репликации. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Потребление памяти pcsd-ruby растёт при открытом веб-интерфейсе

| Поле | Значение |
| --- | --- |
| Тикет | BZ#1860626 |
| Компонент | pcsd |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Потребление памяти pcsd-ruby растёт при открытом веб-интерфейсе.

## Решение

Используйте сборку компонента «pcsd» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#1860626.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- При длительно открытой веб-консоли память процесса pcsd-ruby постоянно увеличивается.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Замеры RSS по времени, версия pcs, длительность сеанса и журналы службы. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Список поиска DNS со значением точки порождает повторные запросы

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-153056 |
| Компонент | glibc / DNS |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Список поиска DNS со значением точки порождает повторные запросы.

## Причина и условия

Если единственный элемент списка поиска в `/etc/resolv.conf` — `.`, резолвер glibc мог повторить запрос для отсутствующего имени.

## Решение и проверка

После обновления glibc повторите запрос через системный резолвер с тем же `search .` и сравните число запросов по журналу тестового DNS-сервера.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- При search . резолвер отправляет два запроса для отсутствующего имени.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Содержимое search, имя тестового запроса и журнал DNS-сервера. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

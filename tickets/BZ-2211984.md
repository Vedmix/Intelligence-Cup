# Роль podman неверно задаёт unqualified-search-registries

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2211984 |
| Компонент | Системная роль podman |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Роль podman неверно задаёт unqualified-search-registries.

## Решение

Используйте сборку системных ролей с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2211984.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Настроенные через роль Podman реестры не используются для коротких имён образов.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Переменные плейбука и итоговый registries.conf без учётных данных. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Установщик не видит iSCSI LUN при CHAP из iBFT

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2213769 |
| Компонент | iSCSI / Anaconda |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Установщик не видит iSCSI LUN при CHAP из iBFT.

## Причина и условия

При аппаратном iSCSI offload установщик не использовал данные аутентификации CHAP из таблицы iBFT.

## Решение

Используйте установочный образ с исправлением в `udisks2-2.9.4-9.el9`. Проверьте, что нужный LUN виден в установщике и при первом запуске.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- В установщике не появляются диски iSCSI при передаче CHAP через firmware.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Настройка offload и iBFT без секретов, результат входа iSCSI и журнал установки. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

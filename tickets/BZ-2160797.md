# Команды cms и smime не шифруют файлы в режиме FIPS

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2160797 |
| Компонент | OpenSSL |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Команды cms и smime не шифруют файлы в режиме FIPS.

## Решение

Используйте сборку компонента «OpenSSL» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2160797.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Шифрование CMS или S/MIME ломается только после включения FIPS.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Подкоманда OpenSSL, тип ключа, алгоритм, режим FIPS и stderr. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

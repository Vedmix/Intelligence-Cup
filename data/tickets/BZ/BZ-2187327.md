# fence_scsi не находит общие устройства lvmlockd автоматически

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2187327 |
| Компонент | fence_scsi |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

fence_scsi не находит общие устройства lvmlockd автоматически.

## Причина и условия

Автоопределение общих устройств `lvmlockd` ломалось при незаданном атрибуте `devices`.

## Решение

После обновления проверьте автоопределение на отдельном стенде с общими устройствами `lvmlockd` и без явного списка `devices`.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Без явного devices агент fencing не подхватывает общие диски под lvmlockd.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Параметры fence_scsi, список общих устройств и журнал агента. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

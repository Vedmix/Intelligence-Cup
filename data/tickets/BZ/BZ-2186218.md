# Роль rhc с ключом активации падает на уже зарегистрированном узле

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2186218 |
| Компонент | Системная роль rhc |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Роль rhc с ключом активации падает на уже зарегистрированном узле.

## Решение

Используйте сборку системных ролей с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2186218.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Прогон rhc с activation key завершается сбоем на зарегистрированной машине.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Состояние регистрации, структура rhc_auth без значения ключа и ошибка Ansible. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

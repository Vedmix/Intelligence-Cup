# nm-cloud-setup удаляет дополнительные IP-адреса

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2151040 |
| Компонент | NetworkManager / nm-cloud-setup |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптомы

На облачном узле дополнительные IP-адреса, добавленные вручную или другим сервисом, пропадают после очередного запуска `nm-cloud-setup` по таймеру.

## Причина

При повторной настройке интерфейса `nm-cloud-setup` удалял адреса, добавленные отдельно от него.

## Решение

Обновите NetworkManager до сборки с исправлением.

## Проверка

На тестовом узле сравните `ip address show dev <интерфейс>` до и после очередного срабатывания `nm-cloud-setup.timer`. Дополнительный адрес должен сохраниться.

## Диагностика на стенде

Зафиксируйте `rpm -q NetworkManager NetworkManager-cloud-setup` и состояние `systemctl list-timers --all nm-cloud-setup.timer`. Сопоставьте изменение списка адресов с записью очередного запуска в `journalctl -b -u nm-cloud-setup.service`. Проверяйте адрес, который отсутствует в метаданных облака и был добавлен отдельно.

# Программа с PAPI зависает при завершении

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2215582 |
| Компонент | PAPI |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Программа с PAPI зависает при завершении.

## Решение

Используйте сборку компонента «PAPI» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2215582.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Процесс с PAPI аварийно останавливается во время завершения.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версия PAPI, включённые компоненты и стек сбоя. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Агент mysql без необходимости переносит роль Promoted между узлами

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2179003 |
| Компонент | Pacemaker |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Агент mysql без необходимости переносит роль Promoted между узлами.

## Условия и признаки

Ресурс MySQL в promotable clone без ожидаемой причины меняет узел с ролью `Promoted`.

## Причина

Оценки продвижения ресурса менялись между состояниями `Promoted` и `Unpromoted`, из-за чего кластер выбирал другой узел.

## Диагностика и проверка исправления

Сохраните `pcs status --full`, журналы Pacemaker и время смены роли. После обновления агента проверьте на тестовом кластере, что при стабильном состоянии узлов очередной цикл мониторинга не приводит к смене роли.

## Решение
Используйте сборку компонента «Pacemaker» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2179003.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Продвинутая реплика MySQL переезжает на другой узел без сбоя текущего.

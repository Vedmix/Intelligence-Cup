# Импорт в LMDB занимает слишком много времени

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2116948 |
| Компонент | Directory Server |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Импорт в LMDB занимает слишком много времени.

## Причина и условия

Потоки импорта LDIF ждали обработки родительских записей при построении индекса `entryrdn`. Конкуренция за блокировки снижала скорость.

## Решение и проверка

Сравните время импорта одного и того же LDIF в тестовые LMDB-базы до и после обновления. После исправления рабочие потоки берут сведения о родителях из временной базы.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Загрузка LDIF в LMDB резко замедляется на этапе индексирования.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Размер LDIF, версия Directory Server, длительность импорта и журналы индексации. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Постраничный поиск обычного пользователя ухудшает производительность

| Поле | Значение |
| --- | --- |
| Тикет | BZ#1974242 |
| Компонент | Directory Server |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Постраничный поиск обычного пользователя ухудшает производительность.

## Решение

Используйте сборку компонента «Directory Server» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#1974242.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- LDAP-запросы с разбивкой на страницы от непривилегированного аккаунта замедляют сервер.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** LDAP-фильтр, размер страницы, роль bind-пользователя и замеры задержки. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Агент azure-events-az выдаёт ошибку с Pacemaker 2.1

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2182415 |
| Компонент | Pacemaker |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Агент azure-events-az выдаёт ошибку с Pacemaker 2.1.

## Причина и условия

Агент разбирал вывод `crm_simulate -Ls` и ожидал строку `Transition Summary:`, которая исчезла начиная с Pacemaker 2.1.

## Решение

На стенде с Pacemaker 2.1 или новее проверьте запуск мониторинга агента и убедитесь, что отсутствие заголовка больше не вызывает ошибку.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После перехода на Pacemaker 2.1 ломается разбор симуляции в azure-events-az.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версии Pacemaker и агента, журнал агента и вывод crm_simulate -Ls. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

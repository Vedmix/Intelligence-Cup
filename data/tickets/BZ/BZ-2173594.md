# После обновления ядра Intel I350 Fiber теряет линк на некоторых SFP

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2173594 |
| Компонент | igb |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

После обновления ядра Intel I350 Fiber теряет линк на некоторых SFP.

## Причина и условия

Драйвер `igb` пытался инициализировать I²C для чтения датчика температуры, которого не было в SFP-модуле.

## Решение

Загрузите ядро с исправлением и проверьте `ethtool <интерфейс>` на том же SFP. При исправном соединении порт должен поднять линк.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После смены ядра оптический порт I350 не поднимается с установленным трансивером.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версия ядра, модель SFP, ethtool и журнал igb. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Повторный запуск роли kdump лишний раз меняет authorized_keys

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2232241 |
| Компонент | Системная роль kdump |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Повторный запуск роли kdump лишний раз меняет authorized_keys.

## Решение

Используйте сборку системных ролей с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2232241.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Повторное применение роли kdump снова меняет файл разрешённых SSH-ключей.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Результаты двух прогонов Ansible и обезличенный diff authorized_keys. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

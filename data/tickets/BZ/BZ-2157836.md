# Пакеты с подписями IMA не устанавливаются без расширенных атрибутов ФС

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2157836 |
| Компонент | RPM / IMA |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Пакеты с подписями IMA не устанавливаются без расширенных атрибутов ФС.

## Решение

Используйте сборку компонента «RPM / IMA» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2157836.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Транзакция установки RPM с IMA-подписями срывается на файловой системе без xattr.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Тип ФС, параметры монтирования, пакет и сообщение RPM. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

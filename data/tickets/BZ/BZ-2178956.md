# Графическое устройство NVIDIA перестаёт работать после выключения ВМ

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2178956 |
| Компонент | Виртуализация / NVIDIA |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Графическое устройство NVIDIA перестаёт работать после выключения ВМ.

## Решение

Используйте сборку компонента «Виртуализация / NVIDIA» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2178956.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После остановки гостевой системы проброшенный GPU NVIDIA перестаёт отвечать.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Модель GPU, схема passthrough, журналы QEMU и ядра при выключении. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

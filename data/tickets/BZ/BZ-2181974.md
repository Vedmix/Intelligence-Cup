# which завершается ошибкой в каталоге с длинным путём

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2181974 |
| Компонент | which |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптомы

При запуске `which` из каталога с путём длиннее 256 символов команда сообщает `Can’t get current working directory`.

## Причина

Программа использовала фиксированное ограничение длины пути в 256 символов.

## Решение

Обновите пакет `which`. Исправленная программа использует `PATH_MAX`.

## Проверка

Из тестового каталога с путём длиннее 256 символов выполните `which bash`. Команда должна вывести путь к `bash`, если тот доступен через `PATH`.

## Диагностика на стенде

Зафиксируйте `rpm -q which` и используйте явный вызов `/usr/bin/which bash`, чтобы исключить подмену команды оболочкой. Для контроля выполните ту же команду из короткого пути, затем из длинного абсолютного пути, составленного из нескольких каталогов. Сравните вывод и коды завершения.

# Консоль VNC недоступна при некоторых разрешениях

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2030836 |
| Компонент | Виртуализация / VNC |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Консоль VNC недоступна при некоторых разрешениях.

## Решение

Используйте сборку компонента «Виртуализация / VNC» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2030836.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- В VNC при определённом размере экрана часть изображения обрезается или указатель смещён.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Разрешение, клиент VNC, настройки видео ВМ и скриншот. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

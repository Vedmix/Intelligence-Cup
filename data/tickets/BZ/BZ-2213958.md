# Проверка срока действия пароля захватывает нелокальные учётные записи

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2213958 |
| Компонент | OpenSCAP |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Проверка срока действия пароля захватывает нелокальные учётные записи.

## Решение

Используйте сборку компонента «OpenSCAP» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2213958.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Проверка возраста пароля срабатывает на сетевых аккаунтах.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** ID правил OpenSCAP и источник учётной записи без содержимого shadow. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

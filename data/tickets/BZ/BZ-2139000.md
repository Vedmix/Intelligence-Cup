# GRUB сообщает об исчерпании памяти при включённых FADump и Secure Boot

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2139000 |
| Компонент | kexec-tools |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.2 |

## Симптомы

При перезагрузке системы с включёнными Firmware Assisted Dump и Secure Boot GRUB может сообщить об ошибке Out of Memory.

## Причина

Ошибка проявлялась, если один из загрузочных компонентов выходил за пределы выделенной области памяти.

## Решение

Установите обновление `kexec-tools` с исправлением совместной работы FADump и Secure Boot.

## Проверка

На тестовом узле с обоими включёнными механизмами выполните перезагрузку. Система должна пройти GRUB и загрузиться без этой ошибки.

## Диагностика на стенде

На стенде зафиксируйте `rpm -q kexec-tools`, состояние FADump и Secure Boot и вывод консоли загрузки. Повторите перезагрузку с теми же загрузочными компонентами. Искомый симптом возникает до запуска ОС, поэтому для диагностики нужен вывод GRUB с консоли, например через удалённую консоль сервера.

## Переписка в Bugzilla

Комментарии Bugzilla не удалось прочитать. Описание причины и решения взято из примечаний Red Hat к выпуску.

## Другие формулировки симптома

- С включёнными FADump и Secure Boot перезапуск останавливается в GRUB с Out of Memory.

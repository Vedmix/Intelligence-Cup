# После выполнения subscription-manager в терминале остаётся лишний текст

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2136694 |
| Компонент | Subscription Manager |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

После выполнения subscription-manager в терминале остаётся лишний текст.

## Решение

Используйте сборку компонента «Subscription Manager» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2136694.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После завершения команды управления подпиской терминал не очищается от служебного вывода.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Подкоманда, версия subscription-manager и запись вывода терминала. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

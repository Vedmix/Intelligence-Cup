# IP-адрес временно исчезает после nmcli device reapply

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2117352 |
| Компонент | NetworkManager |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.2 |

## Симптомы

На интерфейсе с DHCP после изменения профиля и применения настроек через `nmcli device reapply` адрес на короткое время пропадает.

## Причина

При повторном применении профиля NetworkManager терял действующую аренду DHCP.

## Решение

Обновите NetworkManager. Исправленная версия сохраняет аренду до её истечения или запроса новой.

## Проверка

На тестовом интерфейсе выполните `nmcli device reapply <интерфейс>` и наблюдайте за событиями через `ip monitor address`. IPv4-адрес не должен исчезать при повторном применении.

## Диагностика на стенде

Профиль должен использовать DHCPv4, а аренда должна быть действующей. Зафиксируйте имя профиля и версию `rpm -q NetworkManager`. Сопоставьте события `ip monitor address` с отметками времени из `journalctl -b -u NetworkManager`. Искомый признак — удаление уже выданного адреса при повторном применении профиля, до получения новой аренды.

**Что запросить при похожем обращении.** Профиль DHCP, интерфейс, журнал NetworkManager и события ip monitor address с отметками времени. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

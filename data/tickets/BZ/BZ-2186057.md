# Изменение размера ключа не запускает новый запрос сертификата

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2186057 |
| Компонент | Системная роль certificate |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Изменение размера ключа не запускает новый запрос сертификата.

## Решение

Используйте сборку системных ролей с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2186057.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Роль certificate считает существующий сертификат подходящим после смены требуемой длины ключа.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Переменная размера, фактический размер открытого ключа и вывод запроса. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Носитель ReaR с OUTPUT=USB не загружается при UEFI Secure Boot

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2196445 |
| Компонент | ReaR |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Носитель ReaR с OUTPUT=USB не загружается при UEFI Secure Boot.

## Причина и условия

ReaR создавал для USB собственный EFI-образ, в котором не хватало модулей GRUB. При включённом Secure Boot требуется подписанная цепочка загрузки.

## Решение

Обновите ReaR, задайте `SECURE_BOOT_BOOTLOADER=/boot/efi/EFI/redhat/shimx64.efi` в `/etc/rear/local.conf` и заново создайте носитель. Проверьте, что пункт восстановления запускается при включённом Secure Boot.

## Переписка

9 мая 2023 Рено Метрих описал конфигурацию `OUTPUT=USB`, ошибки GRUB при запуске восстановления и результат ручной проверки. После копирования подписанных shim и GRUB среда восстановления запустилась.

## Другие формулировки симптома

- Меню восстановления на USB ReaR открывается, но GRUB не запускает среду при Secure Boot.

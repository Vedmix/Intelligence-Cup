# RabbitMQ завершается ошибкой при использовании IPv6

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2184999 |
| Компонент | RabbitMQ |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

RabbitMQ завершается ошибкой при использовании IPv6.

## Решение

Используйте сборку компонента «RabbitMQ» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2184999.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- При включённом IPv6 RabbitMQ получает отказ при чтении состояния IPv6 в procfs.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Журнал RabbitMQ, AVC и состояние IPv6 на узле. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Политике SELinux не хватает разрешений для insights-client

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2190178 |
| Компонент | Insights |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Политике SELinux не хватает разрешений для insights-client.

## Решение

Используйте сборку компонента «Insights» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2190178.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- insights-client получает отказ доступа при активной политике SELinux.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Действие клиента, журнал службы, AVC и версия selinux-policy. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Веб-консоль выдаёт TypeError при привязке ключа Tang к LUKS

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2203361 |
| Компонент | Веб-консоль / NBDE |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Веб-консоль выдаёт TypeError при привязке ключа Tang к LUKS.

## Причина и условия

Веб-консоль ошибалась при проверке того, относится ли ключ к корневой файловой системе. Сбой возникал, когда файловой системы непосредственно на LUKS-контейнере не было.

## Решение и проверка

Обновите веб-консоль. На тестовом томе с исходной схемой после подтверждения ключа проверьте завершение привязки и возможность автоматической разблокировки.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Из окна проверки ключа Tang привязка корневого зашифрованного тома падает с TypeError.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Схема LUKS и LVM, версия веб-консоли и ошибка из консоли браузера. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

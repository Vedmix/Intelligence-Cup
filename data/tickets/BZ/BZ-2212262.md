# dnf-automatic неправильно сообщает код завершения транзакции

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2212262 |
| Компонент | DNF Automatic |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

dnf-automatic неправильно сообщает код завершения транзакции.

## Решение

Используйте сборку компонента «DNF Automatic» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2212262.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Автоматическое обновление сообщает успех, хотя часть операций с пакетами завершилась ошибкой.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Код выхода, журнал dnf-automatic и список затронутых операций. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# rsyslog не запускается без capabilities

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2187745 |
| Компонент | rsyslog |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

rsyslog не запускается без capabilities.

## Решение

Используйте сборку компонента «rsyslog» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2187745.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Сервис rsyslog не стартует в окружении с ограниченными capabilities.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Журнал rsyslog, набор capabilities и параметры запуска службы. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

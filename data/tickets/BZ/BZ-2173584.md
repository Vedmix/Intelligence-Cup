# Горячее подключение watchdog к ВМ завершается ошибкой

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2173584 |
| Компонент | Виртуализация |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Горячее подключение watchdog к ВМ завершается ошибкой.

## Решение

Используйте сборку компонента «Виртуализация» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2173584.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Добавление виртуального watchdog в работающую ВМ отклоняется.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Модель watchdog, команда hotplug, версия QEMU/libvirt и ошибка. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

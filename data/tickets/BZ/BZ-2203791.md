# Проверка домашних каталогов захватывает нелокальных пользователей

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2203791 |
| Компонент | OpenSCAP |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Проверка домашних каталогов захватывает нелокальных пользователей.

## Решение

Используйте сборку компонента «OpenSCAP» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2203791.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- SCAP оценивает домашние каталоги пользователей, полученных из LDAP или NSS.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** ID правила, источники NSS и обезличенные результаты скана. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Установка ядра переключает загрузку на нежелательный вариант ядра

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2184069 |
| Компонент | GRUB |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Установка ядра переключает загрузку на нежелательный вариант ядра.

## Причина и условия

При установке нескольких вариантов ядра выбор мог определяться порядком установки RPM. После исправления учитывается `DEFAULTKERNEL` из `/etc/sysconfig/kernel`.

## Решение

На стенде с несколькими вариантами ядра после установки обновления проверьте `grubby --default-kernel`. По умолчанию должен выбираться свежий экземпляр нужного варианта.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После установки RPM по умолчанию загружается другой тип ядра.

# Служба dirsrv не запускается после перезагрузки

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2179278 |
| Компонент | Directory Server |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Служба dirsrv не запускается после перезагрузки.

## Причина и условия

Запуск `dirsrv` мог опередить завершение `systemd-tmpfiles-setup.service`.

## Решение и проверка

После обновления перезагрузите тестовый узел и проверьте журнал экземпляра `dirsrv`. Служба должна дождаться подготовки временных файлов и успешно стартовать.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Directory Server не поднимается автоматически на свежей загрузке.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Журнал dirsrv и systemd-tmpfiles-setup за одну загрузку. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

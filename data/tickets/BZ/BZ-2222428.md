# Роль firewall падает в check mode при работе с ещё не созданной службой

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2222428 |
| Компонент | Системная роль firewall |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Роль firewall падает в check mode при работе с ещё не созданной службой.

## Решение

Используйте сборку системных ролей с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2222428.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Пробный прогон роли firewall выдаёт ошибку для ещё не созданного сервиса.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Переменные firewall, версия роли и stderr запуска --check. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

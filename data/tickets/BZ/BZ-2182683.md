# Операции IdM завершаются ошибкой при смешении серверов RHEL 8 и 9

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2182683 |
| Компонент | IdM / Kerberos |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

Операции IdM завершаются ошибкой при смешении серверов RHEL 8 и 9.

## Причина и условия

Различия в поддержке подписи Kerberos PAC нарушали совместимость между серверами IdM разных версий.

## Решение и проверка

Обновите все серверы домена, затем перезапустите службы KDC. При старте серверы определяют, поддерживают ли остальные узлы проверку подписи PAC. В тестовом домене повторите операцию, которая завершалась ошибкой.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- В смешанном домене IdM операции ломаются при обращении к серверам разных поколений RHEL.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версии всех KDC, проблемная Kerberos-операция и журналы IdM. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# После перезапуска демона libvirt невозможно подключить virtiofs

| Поле | Значение |
| --- | --- |
| Тикет | BZ#2078693 |
| Компонент | libvirt / virtiofs |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.3 |

## Симптом

После перезапуска демона libvirt невозможно подключить virtiofs.

## Решение

Используйте сборку компонента «libvirt / virtiofs» с исправлением из RHEL 9.3. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру BZ#2078693.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Подключение общей папки virtiofs ломается после рестарта демона виртуализации.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** XML файловой системы гостя, команда подключения и журнал libvirtd или virtqemud. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

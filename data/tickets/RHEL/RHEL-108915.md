# Миграция ВМ с vTPM на общем хранилище завершается ошибкой

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-108915 |
| Компонент | Виртуализация / vTPM |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Миграция ВМ с vTPM на общем хранилище завершается ошибкой.

## Причина и условия

При миграции не создавался отсутствующий на целевом хосте каталог данных vTPM на общей файловой системе, например NFS.

## Решение и проверка

На тестовой паре хостов после обновления повторите миграцию ВМ с vTPM. Проверьте завершение миграции и доступность vTPM в гостевой системе.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- При переносе ВМ с vTPM на другой хост не создаётся каталог данных TPM.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** XML vTPM, тип общего хранилища и журнал миграции libvirt. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

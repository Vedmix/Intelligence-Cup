# Установщик не видит iSCSI LUN с номером от 256

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-122858 |
| Компонент | Anaconda / iSCSI |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Установщик не видит iSCSI LUN с номером от 256.

## Условия и признаки

Установка на iSCSI может прерваться аварийным завершением Anaconda, если идентификатор LUN равен 256 или больше.

## Причина

Библиотека `blivet` неверно разбирала идентификатор LUN.

## Диагностика и проверка исправления

Сверьте номер LUN на стороне таргета и сохраните журнал установщика. Проверьте обнаружение LUN с исправленным установочным образом на отдельном диске. Для контрольного сравнения можно использовать LUN с номером ниже 256 при тех же параметрах подключения.

## Решение
Используйте сборку компонента «Anaconda / iSCSI» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-122858.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Установка на iSCSI с LUN 256 или больше заканчивается падением Anaconda.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** ID LUN на таргете, версия образа и traceback blivet. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

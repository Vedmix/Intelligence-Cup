# Роль network не находит таблицу маршрутизации по имени

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-112805 |
| Компонент | Системная роль network |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Роль network не находит таблицу маршрутизации по имени.

## Решение

Используйте сборку системных ролей с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-112805.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Ansible не распознаёт имя main при настройке таблицы маршрутов.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Фрагмент плейбука, версия роли и содержимое файлов rt_tables. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

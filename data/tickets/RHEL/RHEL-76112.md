# DNF отклоняет удаление пакета из-за защищённой зависимости

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-76112 |
| Компонент | DNF |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

DNF отклоняет удаление пакета из-за защищённой зависимости.

## Причина и условия

При включённом `clean_requirements_on_remove` DNF пытался удалить защищённую зависимость вместе с единственным пакетом, которому она требовалась. Вся транзакция блокировалась.

## Решение и проверка

В тестовой системе проверьте предварительный план транзакции `dnf remove --assumeno <пакет>`. Исправленный DNF должен оставить защищённую зависимость.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Удаление обычного пакета блокируется попыткой удалить защищённую зависимость.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Предварительный план DNF, protected_packages и clean_requirements_on_remove. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

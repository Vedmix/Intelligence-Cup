# Список участников группы неполон при ERANGE во время объединения записей

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-112149 |
| Компонент | glibc / NSS |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Список участников группы неполон при ERANGE во время объединения записей.

## Решение

Используйте сборку компонента «glibc / NSS» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-112149.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После ERANGE NSS возвращает только часть участников объединённой группы.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Источники NSS, обезличенный размер группы, результат запроса и признак ERANGE. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Фильтр advisory вызывает логическую ошибку при обновлении пакетов разных архитектур

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-103995 |
| Компонент | DNF |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Фильтр advisory вызывает логическую ошибку при обновлении пакетов разных архитектур.

## Условия и признаки

Обновление через DNF с фильтром `--security` может не разрешиться при наличии нескольких архитектур `libldb` или `libsmbclient`.

## Причина

Ошибка в `libsolv` проявлялась при разрешении многoархитектурной транзакции с фильтром advisory и параметрами решателя `forcebest` и `implicitobsoleteusescolors`.

## Диагностика и проверка исправления

Зафиксируйте архитектуры установленных пакетов, доступные репозитории и полный вывод транзакции. На тестовой системе после обновления повторите `dnf upgrade --security --assumeno` с тем же набором репозиториев. План обновления должен строиться без ошибки решателя.

## Решение
Используйте сборку компонента «DNF» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-103995.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- dnf upgrade --security не может решить multilib-транзакцию.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Архитектуры пакетов, параметры libsolv, advisory и полный текст ошибки. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

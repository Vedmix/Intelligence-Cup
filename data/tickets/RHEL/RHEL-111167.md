# Регистратор Keylime повреждает сертификаты EK

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-111167 |
| Компонент | Keylime |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Регистратор Keylime повреждает сертификаты EK.

## Решение

Используйте сборку компонента «Keylime» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-111167.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- После регистрации Keylime сертификат ключа подтверждения TPM оказывается повреждён.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версия регистратора и контрольные суммы EK-сертификата до и после передачи. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

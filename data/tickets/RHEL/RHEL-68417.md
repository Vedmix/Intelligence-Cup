# Clevis молча игнорирует неизвестные поля конфигурации TPM2

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-68417 |
| Компонент | Clevis / TPM2 |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Clevis молча игнорирует неизвестные поля конфигурации TPM2.

## Причина и условия

При шифровании Clevis мог проигнорировать опечатку в имени поля, например `pcrs_ids` вместо `pcr_ids`. Привязка могла создаться с другими параметрами PCR.

## Решение и проверка

На стенде проверьте обработку конфигурации с неизвестным полем. Исправленная версия должна явно сообщить об ошибке.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Опечатка в параметре TPM2 проходит без сообщения об ошибке при шифровании Clevis.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Конфигурация pin с удалёнными секретами, имя поля и вывод команды. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# Роль storage падает при отсутствии /etc/fstab

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-123044 |
| Компонент | Системная роль storage |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Роль storage падает при отсутствии /etc/fstab.

## Условия и признаки

Роль `storage` аварийно завершается на узле, где отсутствует `/etc/fstab`.

## Причина

Роль пыталась читать таблицу файловых систем без предварительной проверки существования файла.

## Диагностика и проверка исправления

Проверьте `test -e /etc/fstab` на управляемом узле и сохраните имя задачи и вывод Ansible. Повторите плейбук с обновлённой ролью на тестовом узле, где файл отсутствует изначально. Роль должна пройти шаг чтения конфигурации без исключения.

## Решение
Используйте сборку системных ролей с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-123044.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- На узле без таблицы монтирования роль storage падает на чтении fstab.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Результат проверки наличия файла, имя задачи и вывод Ansible. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

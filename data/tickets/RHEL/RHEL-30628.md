# Apache зависает при передаче журнала аудита по каналу

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-30628 |
| Компонент | Apache HTTP Server |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

Apache зависает при передаче журнала аудита по каналу.

## Решение

Используйте сборку компонента «Apache HTTP Server» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-30628.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- httpd перестаёт отвечать при настройке вывода аудита через pipe.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Фрагмент настройки piped logging, журнал httpd и время зависания. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

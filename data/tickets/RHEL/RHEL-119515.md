# scp неверно обрабатывает относительные пути с ..

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-119515 |
| Компонент | OpenSSH |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

scp неверно обрабатывает относительные пути с ...

## Решение

Используйте сборку компонента «OpenSSH» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-119515.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Передача scp с переходом в родительский каталог неправильно разрешает путь.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Команда с относительным путём, направление передачи, версия OpenSSH и stderr. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

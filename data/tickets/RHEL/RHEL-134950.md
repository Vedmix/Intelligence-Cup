# adcli testjoin ошибается в выборе домена при нескольких principal в keytab

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-134950 |
| Компонент | adcli |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

adcli testjoin ошибается в выборе домена при нескольких principal в keytab.

## Условия и признаки

При наличии principal из нескольких доменов в keytab команда `adcli testjoin` может вернуть `Realm not local to KDC`, хотя узел присоединён к нужному домену.

## Причина

Проверка могла выбрать realm по первой записи в keytab вместо realm нужного машинного аккаунта.

## Диагностика и проверка исправления

Проверьте список principal командой `klist -k` и сопоставьте realm с ожидаемым доменом. После обновления `adcli` повторите проверку с тем же keytab. Явное указание ожидаемого домена помогает сравнить результаты диагностики.

## Решение
Используйте сборку компонента «adcli» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-134950.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Машина состоит в домене, но testjoin обращается не к тому realm.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Обезличенный вывод klist -k, ожидаемый realm и stderr adcli. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.

# AIDE аварийно завершается при изменении наблюдаемого файла

| Поле | Значение |
| --- | --- |
| Тикет | RHEL-1569 |
| Компонент | AIDE |
| Статус | Исправлено по данным Red Hat |
| Релиз с исправлением | RHEL 9.8 |

## Симптом

AIDE аварийно завершается при изменении наблюдаемого файла.

## Решение

Используйте сборку компонента «AIDE» с исправлением из RHEL 9.8. Для другой ветки или канала обновлений сверяйте наличие исправления по номеру RHEL-1569.

## Данные из трекера

Описание исправления сверено с примечаниями к выпуску. Переписка для этой карточки не собрана.

## Другие формулировки симптома

- Проверка целостности AIDE прерывается, если файл меняется во время чтения.

## Диагностические данные

**Что есть в источнике.** По доступным материалам состав собранных при расследовании данных не установлен.

**Что запросить при похожем обращении.** Версия AIDE, правило для пути, stderr и порядок изменения файла. Также нужны версия RHEL, точная сборка затронутого компонента и время проявления сбоя.
